## 重做 GitHub 主页（Goblin-Master/Goblin-Master）

**背景**：这个仓库同时是 GitHub profile 仓库（README）和 GitHub Pages 站点（index.html）。

**发现的原问题**：
- `index.html` 第 647 行有语法错误 `n            });`（多一个 `n`），整段脚本不执行 → 所有 `loading-skeleton` 永久停留。
- 多处 class 属性写成 `mb-2\"`（转义引号），属性失效。
- 用 `Math.random()` 伪造 star / commit / contribution 数，公开主页上很掉分。
- README 混用 Font Awesome + shields 多套图标，还残留 `your.email@example.com`、`linkedin.com/in/yourprofile` 占位符。

**改法 / 现在的设计体系**：
- 配色：墨色 `#0B0C0E` + 铜色 `#E0A458`，冷色只用 `#5EC8B8` 一点点。刻意避开青紫渐变那套。
- `assets/banner-dark.svg` / `banner-light.svg`，README 用 `<picture>` + `prefers-color-scheme` 自动切主题。
- README 结构：横幅 → 徽章 → 关于（精简 Go struct）→ 正在做（goblin 细节）→ 其他项目表格 → 技术栈（skillicons）→ 数据（github-readme-stats 定制配色）→ 联系。
- `index.html` + `styles.css` 重写为设计令牌驱动，数据走 GitHub API，失败时保留硬编码真实值（18 repos / 18 stars / 9 followers）而不是占位符。支持 `prefers-reduced-motion`。

**验证方式**：Chrome headless 截图；用 iframe 探针量 `scrollWidth` 确认移动端无横向溢出（`--window-size=430` 直出截图会因 Chrome 最小窗口宽度被裁切，别误判）。
